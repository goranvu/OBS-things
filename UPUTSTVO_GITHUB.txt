BROJ GLEDALACA ISPOD KOMANDI ZA TRANZICIJU U STUDIO MODU
=====================================================

Ovaj dodatak prikazuje zuti broj ispod tranzicija i T-bar klizaca,
izmedju Preview i Program displeja. Broj je deo OBS interfejsa i nije
deo scene niti se pojavljuje u snimku/strimu.

INSTALACIJA (Windows x64)
1. Zatvori OBS.
2. Raspakuj paket tako da dobijes:
   C:\ProgramData\obs-studio\plugins\obs-fixed-counter\bin\64bit\obs-fixed-counter.dll
   C:\ProgramData\obs-studio\plugins\obs-fixed-counter\data\locale\en-US.ini
   Ako vec imas stariji obs-fixed-counter dodatak, zameni njegov DLL.
3. Pokreni OBS i ukljuci Studio Mode.
4. Broj ce se pojaviti ispod komandi za tranziciju.

Broj se proverava svakih 5 sekundi kada YouTube odgovara na vreme.
Pre pocetka prenosa prikazuje se broj onih koji cekaju.
Tokom prenosa prikazuje se broj trenutnih gledalaca.
Ako broj nije dostupan, prenos je zavrsen ili je podatak zastareo,
prikazuje se —. Stvarni broj 0 se prikazuje kao 0.
Ako zahtev traje duze, ne pokrece se novi zahtev dok prethodni ne zavrsi.
YouTube moze objavljivati promene broja sporije od provere na 5 sekundi.

Za ovaj dodatak ne trebaju Python, lokalni server niti YouTube Data API kljuc.
HTTPS koristi Windows WinHTTP/Schannel, a ne Qt TLS dodatke.
Provera sertifikata ostaje ukljucena; mreza radi u pozadinskoj niti.
Stari obs_gledaoci.py mozes ukloniti ako si ga dodao; dodatak radi samostalno.
GitHub YouTube panel moze ostati na svojoj javnoj adresi.
Brojac ima sopstveni izbor kanala; ne cita izbor iz Browser Dock panela.

PROVERE I OGRANICENJA
DLL se prevodi na GitHub-ovom Windows racunaru. Automatski testovi proveravaju
parser, cekanje/uzivo/nulu, nepodrzane podatke, izbor kanala i dodavanje,
uklanjanje i ponovno dodavanje broja u Studio Mode raspored.
Test rasporeda koristi Qt prozor istog oblika, a nije stvarna OBS sesija.
Raspored je proveren prema izvornom kodu OBS 31.1.1. Ako novija verzija
promeni unutrasnji raspored, dodatak ne ubacuje broj na nepoznato mesto;
u OBS logu ostavlja poruku o neprepoznatom rasporedu.
YouTube javni format moze da se promeni ili da zahteva prijavu/saglasnost.
U tom slucaju prikazuje se — i treba prilagoditi citanje.
