BROJ GLEDALACA U OBS STATUS BARU — VERZIJA 2.2
================================================

Zatvori OBS i zameni stari obs-fixed-counter.dll ovim DLL-om.
Paket raspakuj u:
%ProgramData%\obs-studio\plugins\obs-fixed-counter\

DLL mora da zavrsi na:
%ProgramData%\obs-studio\plugins\obs-fixed-counter\bin\64bit\obs-fixed-counter.dll

Pokreni OBS. Broj je sada skroz levo u status baru, umesto izmedju
Preview i Program panela. Vidljiv je i van Studio moda.
Koristi font i boju postojecih statusnih podataka, bez velikih zutih cifara.
Prikazuje samo broj, bez naslova i bez bilo kakvog hinta na prelazak misem.
Status bar mora biti ukljucen u OBS-u da bi se broj video.

Kanal menjas preko Tools / Alati > Broj gledalaca - kanal.
Pri azuriranju se prethodno zapamceni kanal cuva.
Unos moze biti @imeKanala, Channel ID, YouTube adresa kanala /live,
ili link konkretnog prenosa.

Provera ide svakih 5 sekundi kada YouTube odgovara na vreme.
Pre pocetka prikazuje se broj ljudi koji cekaju, a tokom prenosa broj gledalaca.
Ako broj nije dostupan, prikazuje se —; stvarnih nula se prikazuje kao 0.
Poruke o greskama se nalaze u OBS logu, a ne u tooltipu broja.

HTTPS i dalje koristi Windows WinHTTP/Schannel, sa proverom sertifikata.
Python, lokalni server i YouTube Data API kljuc nisu potrebni.

Windows automatski testovi proveravaju parser, status bar raspored,
poravnanje, font, odsustvo tooltipa, promenu velicine prozora i HTTPS vezu.
Stvarni prikaz u korisnikovom OBS-u treba proveriti nakon zamene DLL-a.

Uklanjanje: zatvori OBS i ukloni obs-fixed-counter.dll iz navedenog foldera.
