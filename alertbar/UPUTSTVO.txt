OBS Automatic Line In Sound Level Control v3.0
=====================================================
Windows 10, OBS Studio 31.x (x64)

INSTALL
- Close OBS completely.
- Copy obs-linein-alert directory from ZIP to
  C:\ProgramData\obs-studio\plugins\
- Start OBS. There is NO longer any thin volume bar or Auto checkbox under Program.
- Open OBS menu Tools > Аутоматска контрола нивоа звука
- The item is CHECKED every time OBS starts. It is not persisted as OFF.
- Click the checked item to DISABLE all automatic level corrections.
- Click again to ENABLE them. The existing Windows Recording gain is not
  automatically reverted upon disabling.

SAME ADAPTIVE CONTROL AS v2.2
- Sustained peaks close to clipping for two seconds: Windows Line In DOWN 3 dB.
- Sustained quiet/modulated sound: Windows Line In UP 2 dB in slow steps.
- Never boost background silence or steady noise.
- Maximum +/-18 dB from baseline, bounded by hardware Recording level range.
- NO speech/music classification; NO video or volume UI in Program display.
- The Windows Recording capture endpoint must be named Line In, or the
  previously supported settings.ini device_id override must be used.
- If no usable Line In device, the menu item may still be CHECKED, but
  no hardware adjustment can be made. See OBS logs for the reason.

LOG: OBS Help > Log Files > View Current Log; search [Line In Alert].
The previous viewer-count plugin remains untouched.

Note: If clipping happens before sound-card ADC, changing Windows software
Recording gain will not remove that distortion.
