OBS Line In Alert Bar v2.1 – adaptive Auto gain, Windows / OBS 31.x
=======================================================================
Close OBS. Copy the obs-linein-alert folder from the ZIP to:
C:\ProgramData\obs-studio\plugins\
Enable Studio Mode. Under Program view: fixed 4 px indicator and checkbox Auto.
AUTO is initially OFF. Turn it on to let the DLL adjust WINDOWS RECORDING
Line In input level (not OBS mixer or loudspeaker output).

- If the actual captured PCM signal reaches >= 89% full scale in each of
  8 consecutive 250 ms windows (2 seconds), gain DECREASES by 3 dB.
- After sustained QUITER signal, at least ~2.5s of audible audio in a
  sliding 6s window, most of its peaks <= 65%, gain INCREASES 1 dB.
  A further increase requires 3 seconds, limiting pumping.
- SILENCE and low level background hiss do not trigger increase.
- Recovery ceiling is the actual Windows Line In level at the FIRST time
  Auto is turned on in that plugin worker; it never increases past that.
- Automatic reduction limited to 18 dB BELOW that initial level.
- No classification of voice/music. This only measures PCM amplitude.
- If a hardware device clips BEFORE A/D conversion, Windows-level
  software attenuation cannot eliminate existing distortion.
- Some Windows capture interfaces read a signal that is not affected
  by Recording endpoint volume; verify on your actual device.
- OBS Help > Log Files > View Current Log: "[Line In Alert]" shows
  each DOWN/UP gain adjustment.

Previously installed viewer-count plugin unchanged.
