OBS Line In Alert Bar for Windows 10 / OBS Studio 31.x
Close OBS. Copy the obs-linein-alert folder to C:\ProgramData\obs-studio\plugins\
Enable Studio Mode. A thin 4px indicator appears directly below PROGRAM.
Windows Recording endpoint named "Line In" is selected automatically.
GREEN to -12 dBFS; YELLOW -12 to -3 dBFS; RED above -3 dBFS with flashing alert.
No text, no controls, no slider, no automatic gain, no audio changes.
If you have multiple Line In endpoints, edit OBS plugin_config/obs-linein-alert/settings.ini:
[General]
device_id=<Windows MMDevice endpoint ID>
The Windows endpoint peak meter is pre-endpoint attenuation and cannot diagnose all analog pre-ADC clipping.
This plugin does not interfere with the existing viewer-counter DLL.
Tested only algorithmically, not on the physical sound card.

VERSION 1.1: MUSIC DETECTION
During MUSIC-LIKE audio (sustained harmonic and stable spectrum), strip automatically grows from 4 px to 13 px. Speech or silence returns it to 4 px.
Music detection is a lightweight, locally computed heuristic on PCM samples, not a trained AI model; false positives and false negatives are possible, especially with choir, singing, and speech over music. If Windows WASAPI shared capture fails, stays 4 px; peak meter still works. The DLL does not change any audio levels.

v1.2 Diagnostics: In OBS Help > Log Files > View Current Log, search [Line In Alert].
Windows recording endpoints are listed, plus whether WASAPI PCM capture started.
Every 8 seconds: frames, peak, tonalVotes, MUSIC/NOT_MUSIC. This allows troubleshooting.
Detection was loosened for music with changing notes, though this is still an
acoustic heuristic; it is not a pretrained AI speech/music classification model.
