OBS Line In Alert Bar v2.2 - Adaptive two-way Windows Recording Auto gain.
Install as before: C:\ProgramData\obs-studio\plugins\obs-linein-alert\
Close OBS first, replace DLL, restart. In Studio Mode, fixed 4px bar and Auto checkbox.

FIX: Earlier versions did NOT allow ANY automatic amplification past the Windows
input level at the time Auto was first checked. This version CAN increase beyond
the initial input gain, up to +18dB (if the Windows sound card supports it).
It cannot exceed the sound card's Windows Recording maximum level.

QUIET SPEECH: Around 4 seconds of quiet, modulated sound (peak as low as 0.3%
of full digital scale, RMS >=0.06%) triggers a +2dB input-level increase.
Further increases are at most every 3 seconds. Silence or continuous steady
background noise do not trigger increases. If input becomes too strong,
the existing -3dB adjustment still fires after 2s >= about 90% peaks.
No voice/music classification needed. AUTO checkbox stays opt-in.

SAFE LIMITS: +/-18dB around the initial Windows input level; Windows hardware
minimum and maximum respected. Auto remains off unless user checks it.
Even with +18dB, extremely quiet sound may remain quiet. If Windows level is
already at hardware maximum, NO plugin can increase that particular hardware
input level using the Windows Recording-volume control.
With some drivers, software volume doesn't prevent ADC clipping.

TROUBLESHOOTING: Help > Log Files > View Current Log, search [Line In Alert].
The v2.2 log records UP/DOWN changes and diagnostic PCM input and gain values
every ~8s. Verify actual Windows Sound > Recording > Line In > Levels changes.
